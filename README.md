# C-hesapmakinesi

C Dilinde Butonlu Hesap Makinesi


Bu proje, C dilinde yaptığım bir butonlu hesap makinesi uygulamasıdır. Basit işlemler yapabilir.

Özellikler
Toplama, çıkarma, çarpma ve bölme işlemleri


Kullanıcı dostu butonlarla arayüz
